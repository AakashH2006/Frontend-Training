## What I Learned

The `alt` attribute provides alternative text for an image.

A `<figure>` can group an image with its related caption.

HTML tables are structured using rows, header cells and data cells:

- `<table>` — table
- `<tr>` — table row
- `<th>` — table header cell
- `<td>` — table data cell

Metadata is information about the webpage that is placed inside the `<head>` and is not normally displayed as page content.

A favicon is the small icon associated with a webpage in the browser tab.
