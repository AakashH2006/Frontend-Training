Day 11 — Variables, Values and Operators

Week 3, Day 1. The exercises are in variables.js and all of the output goes to the console. Nothing is written to this page, because the DOM is Week 4.

How to run it

Either of these works, and both run exactly the same file:

  1. Open this page and then open the DevTools console (F12, then the Console tab).
  2. Or run it without a browser at all:
node variables.js

What the file covers

  1. const, let, and why not var
  2. The primitive types and typeof
  3. Numbers, floating point and NaN
  4. Strings and template literals
  5. Explicit conversion against implicit coercion
  6. Truthy and falsy values
  7. == against ===
  8. Logical operators, short circuiting, ?? and ?.
  9. An exercise turning raw string form values into a summary
