Day 21 — TypeScript Setup and Everyday Types

The first day of Week 5, and the first day with a build step. Ten sections on the types used every day, all of them printing to the console in the same shape as the Week 3 exercise files.

Not run yet.

How to run it

npm install
npm run dev

Then open the address Vite prints and the DevTools console (F12, then the Console tab).

There is no way to open this one by double-clicking index.html. The browser cannot run .ts, so the file below is served by Vite and compiled on the way through. That is the difference from every day before this one.

Type-check on its own

npm run typecheck

This is the part that matters, and it is separate from running the app on purpose. Vite strips the types out without checking them, so the dev server will happily serve a file full of type errors. tsc --noEmit is the only thing that actually reads them.

It should report no errors. The file contains ten deliberate mistakes, each one marked @ts‑expect‑error — that comment asserts the line below it is an error, so a clean run means every one of them is still wrong in the way I expected.
