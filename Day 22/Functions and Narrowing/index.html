Day 22 — Functions and Narrowing

Two halves. Typing the things functions are made of, then narrowing — which is how a union stops being a locked box and turns into something usable.

Not run yet.

How to run it

npm install
npm run dev        # then open the console (F12)
npm run typecheck  # 0 errors, with 7 deliberate ones pinned

What the sections cover

  1. Parameters and returns, and the bug an inferred return type allows
  2. Optional parameters against defaults, and why label?: string is not label: string | undefined
  3. Rest parameters, and why a spread needs a tuple
  4. Function types, contextual typing, and the map(parseInt) trap
  5. void, and why it is not undefined
  6. typeof narrowing, and typeof null === "object"
  7. Truthiness narrowing, and where 0 and "" break it
  8. Equality narrowing, and the one good use of != null
  9. The in operator
  10. instanceof, and why catch gives unknown
  11. Discriminated unions, and exhaustiveness with never
  12. Type predicates and assertion functions

The one that mattered

Section 11. Week 4's store had a phase string and four independent fields, so phase: "error" alongside a full results array was a state the code could construct. As a discriminated union it is not constructible, and the never branch means adding a fifth state breaks the build until every branch handles it.
