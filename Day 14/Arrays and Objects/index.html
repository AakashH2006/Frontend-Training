Day 14 — Arrays and Objects

Week 3, Day 4. The exercises are in arrays-objects.js and all of the output goes to the console. Everything is worked on one small product dataset rather than on throwaway examples.

How to run it

  1. Open this page and then the DevTools console (F12, then the Console tab).
  2. Or run it without a browser:
node arrays-objects.js

What the file covers

  1. Which array methods mutate and which return something new
  2. map, filter, find, findIndex, some, every
  3. reduce for sums, grouping and lookup tables
  4. sort comparators, string sorting and multi-key sorting
  5. flat, flatMap and de-duplicating with a Set
  6. Property access, computed keys, Object.entries, spread merging and shallow copies
  7. Array, object, nested and parameter destructuring
  8. An exercise producing a grouped and sorted stock report
