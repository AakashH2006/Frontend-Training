Day 12 — Control Flow and Loops

Week 3, Day 2. The exercises are in control-flow.js and all of the output goes to the console.

How to run it

  1. Open this page and then the DevTools console (F12, then the Console tab).
  2. Or run it without a browser:
node control-flow.js

What the file covers

  1. if / else if / else, ternaries and guard clauses
  2. switch, grouped cases, and what a missing break does
  3. for, while and do...while
  4. for...of, for...in, entries() and forEach
  5. break, continue and labelled loops
  6. Ten exercises: FizzBuzz, grading, vowels, reversing, sums, times tables, largest value, primes, a countdown and a week planner
