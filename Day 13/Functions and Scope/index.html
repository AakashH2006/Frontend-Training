Day 13 — Functions and Scope

Week 3, Day 3. The exercises are in functions.js and all of the output goes to the console.

How to run it

  1. Open this page and then the DevTools console (F12, then the Console tab).
  2. Or run it without a browser:
node functions.js

What the file covers

  1. Declarations, expressions and arrow functions, and hoisting
  2. Default, rest and spread parameters, and pass by value
  3. Return values and the automatic semicolon insertion trap
  4. Global, function and block scope, the scope chain and shadowing
  5. Closures, private state and a once() wrapper
  6. Callbacks and functions that return functions
  7. this in normal against arrow functions
  8. Pure functions and side effects
  9. Recursion over a nested syllabus object
  10. An exercise composing small functions into a report pipeline
