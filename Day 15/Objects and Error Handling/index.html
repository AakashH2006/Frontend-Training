Day 15 — Expense Analyzer

Week 3 mini-project. A console program that takes raw expense rows in the shape a form or a CSV would produce, validates them, reports on the good ones and explains the bad ones.

How to run it

  1. Open this page and then the DevTools console (F12, then the Console tab).
  2. Or run it without a browser:
node expense-analyzer.js

What it does

  • Validates every field — date, description, category and amount — and rejects a row with the line number, the field and the reason
  • Stores money in paise as integers, converting only when printing
  • Groups totals by category and by month, finds the largest expense and the average, and compares each category against a budget
  • Runs three further datasets to exercise the failure paths: all rows invalid, empty input, and a rethrown unexpected error

Error handling

  • ValidationError and EmptyDatasetError as custom classes, so a catch block can tell a bad input apart from a bug
  • Bad rows are collected rather than stopping the run at the first failure
  • Anything that is not a known error type is rethrown, never swallowed
  • finally for the timing line, and error.cause when wrapping one error in another
